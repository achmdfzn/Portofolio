
## Plan: Dark/Light Mode Toggle — "Smooth & Cool"

### 1. Light Theme CSS (`globals.css`)
Tambahkan blok `[data-theme="light"]` override untuk semua `--color-*` variables.
- Background: putih-abu (`#f5f5f5`) bukan putih mentah
- Surface: putih (`#ffffff`)
- Teks: hitam lembut (`#1a1a1a`, `#555555`, `#999999`)
- Aksen cyan: adjust kontras untuk light bg (`#00b8e6`)
- Semua variable lain di-override agar komponen otomatis menyesuaikan (karena pakai `var(--color-*)`)
- Tambahkan `transition: background-color 300ms ease, border-color 300ms ease, color 300ms ease` di `body` untuk transisi halus

### 2. Theme Toggle Icon — Sun & Moon (`components/atoms/icons.tsx`)
Tambah `SunIcon` dan `MoonIcon` mengikuti pattern yang sudah ada (inline SVG, `SVGProps`, `aria-hidden`).
- SunIcon: lingkaran dengan sinar
- MoonIcon: sabit bulan + bintang kecil opsional

### 3. Theme Toggle Button (`components/atoms/theme-toggle.tsx`)
Client component toggle.
- Button bulat (40×40px) dengan icon Sun/Moon sesuai theme aktif
- Animasi: rotate 360° saat toggle, scale 0.9→1.0, pakai `--ease-spring`
- `aria-label` dinamis: "Switch to light mode" / "Switch to dark mode"
- Menggunakan ThemeContext
- Menampilkan icon dengan `transition-transform duration-500`

### 4. ThemeProvider (`components/theme-provider.tsx`)
Client component yang bungkus `{children}`.
- Baca `localStorage.getItem('theme')` di mount
- Fallback ke `window.matchMedia('(prefers-color-scheme: light)')`
- Set `data-theme` attribute di `<html>`
- Ekspos `{ theme, toggleTheme }` via React Context
- Render children dalam Provider

### 5. Anti-flicker Script (`app/layout.tsx`)
Tambahkan inline `<script>` blocking sebelum `{children}` yang:
- Baca `localStorage.theme` atau `matchMedia`
- Set `document.documentElement.dataset.theme`
- Cegah flash theme sebelum React hydrates

### 6. Layout Update (`app/layout.tsx`)
- Tambah `suppressHydrationWarning` di `<html>`
- Import ThemeProvider
- Bungkus content dengan `<ThemeProvider>`
- Tambah `<ThemeToggle />` di posisi fixed top-right (atau di hero section — rekomendasi: fixed top-right biar selalu aksesibel)

### 7. Tambah Animasi Transisi Global (`globals.css`)
```css
*, *::before, *::after {
  transition: background-color 300ms ease,
              border-color 300ms ease,
              color 300ms ease;
}
```
Kecuali untuk `prefers-reduced-motion`.
